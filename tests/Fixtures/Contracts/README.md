Examples for GET contracts/contract_requests list and details. The capitation detail examples omit the required contractor_employee_divisions array; an empty array is supplied to satisfy the published schema. Program arrays follow the UUID-string examples. is_suspended is a string in list responses and a boolean in details. No live records are used.

`contractor-employee-division.json` contains the example values from the capitation detail response schema's employee/division properties (the published single-value enums), covering the non-empty staff and speciality variant.
